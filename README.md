
# KVN Improvement

## Chức năng

- Nhúng Google Apps Script Web App trong GitHub Pages.
- Hỗ trợ hiển thị trên điện thoại và máy tính.
- Giữ URL GitHub Pages khi ứng dụng được nhúng thành công.

## Công nghệ

- GitHub Pages
- HTML, CSS, JavaScript
- Google Apps Script
- Google Sheets
